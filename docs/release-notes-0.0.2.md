Исправляющий выпуск FilesConverter.

- устранено бесконечное ожидание при конвертации и объединении: фоновые задачи теперь
  гарантированно существуют до фактического завершения;
- в строке состояния отображается прошедшее время, а после операции — точная длительность;
- параметры объединения разделены на папку, имя итогового файла и формат;
- название книги и автор показываются только для FB2 и больше не конфликтуют с именем файла;
- расширение `.txt` или `.fb2` автоматически соответствует выбранному формату;
- для TXT явно указано ожидаемое время: несколько файлов обычного книжного размера
  объединяются, как правило, меньше чем за секунду.
