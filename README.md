# FilesConverter

Windows-приложение для пакетной конвертации и объединения книг в форматах TXT и FB2.

## Возможности

- TXT → FB2 и FB2 → TXT;
- выбор нескольких файлов через диалог или перетаскиванием;
- смешанная пакетная конвертация: каждый файл превращается в противоположный формат;
- ручная перестановка файлов перед объединением;
- общий результат в TXT или FB2;
- названия исходных книг как отдельные разделы;
- метаданные названия и автора для объединённого FB2;
- чтение TXT в UTF-8, UTF-16 и Windows-1251;
- автоматическое добавление номера к имени вместо случайной перезаписи;
- фоновая обработка без зависания интерфейса;
- проверка обновлений через GitHub Releases и запуск нового установщика.

## Установка

Скачайте установщик из
[последнего релиза](https://github.com/Granik115/FilesConverter/releases/latest) и
запустите его. Программа устанавливается для текущего пользователя, поэтому права
администратора обычно не нужны.

## Как пользоваться

### Конвертация

1. Откройте вкладку «Конвертация».
2. Добавьте один или несколько `.txt`/`.fb2`.
3. Выберите папку результата.
4. Нажмите «Конвертировать».

TXT-файлы станут FB2, а FB2-файлы — TXT. Если файл с таким именем уже существует и
перезапись выключена, программа создаст имя вида `Книга (1).fb2`.

### Объединение

1. Откройте вкладку «Объединение».
2. Добавьте файлы и выставьте порядок перетаскиванием либо кнопками «Выше/Ниже».
3. Выберите формат, папку и имя итогового файла.
4. Поля «Название книги» и «Автор» появляются только для FB2.
5. Нажмите «Объединить».

При объединении FB2 текст извлекается и заново укладывается в чистую FB2-структуру.
Это позволяет надёжно склеивать книги из разных источников, но встроенные изображения,
сноски-ссылки и сложное исходное форматирование пока не переносятся.

## Разработка и сборка

Требуются Python 3.10+ и Inno Setup 6.

```powershell
.\build.ps1
```

Скрипт запускает тесты, создаёт приложение через PyInstaller и собирает установщик в
`releases\`. GitHub Actions выполняет те же шаги на Windows и публикует установщик при
изменении версии.
